Core Capabilities

Built for
Enterprise Security

⬢
Role-Based Access

Three distinct roles — IT Admin, HR Admin, and Employee — with granular permissions enforced at every API endpoint. JWT tokens with 30-minute expiry ensure session security.

◈
Read-Only PDFs

Every uploaded document is programmatically protected with pikepdf. Owner passwords, permission flags, and optional user watermarks prevent unauthorized modification.

◎
Full Audit Trail

Every VIEW, DOWNLOAD, UPLOAD, and DELETE action is logged with user ID, IP address, user-agent, and timestamp. Immutable compliance records out of the box.

◇
Compliance Acks

Mark documents as requiring acknowledgment. Employees must explicitly confirm they've read critical policies. Track completion status per document per user.

▦
Version Control

Automatic version history tracks every document revision with change logs and creator attribution. Soft deletes preserve data integrity with full archive recovery.

⬡
Smart Search

Filter documents by title, tags, department, and type. Department-scoped views ensure employees only surface relevant documents from their teams.
